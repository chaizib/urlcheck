# urlcheck

定时检查目标端点可用性。
每天 04:00 和 13:00 自动运行，支持手动触发。
记录保留最近7天。

## 配置方式
Secrets,Actions：
`TARGET_URL` `TG_BOT_TOKEN` `TG_USER_ID`
